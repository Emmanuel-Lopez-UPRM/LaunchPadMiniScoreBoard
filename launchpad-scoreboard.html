Phone setup & fair finishes

Open the hosted HTTPS site in Safari or Chrome, allow camera access, and keep this tab visible. Use landscape if it fits your track better. Secure the phone above or beside the course so both finish positions line up with the digital line. Calibrate with an empty, well-lit track; arm before releasing the balls. Test each lane at race speed before playing.

This is motion-based detection: hands, moving shadows, or a shaking phone can cause false results. Very fast or tiny balls may be missed. Close finishes need human review; the saved image is a sampled frame, not a high-speed photo finish. Camera interruptions cancel an armed race. Pairing uses WebRTC; some school/public networks block it. There is no relay server, so use another Wi-Fi network if pairing fails.

Launchpad controls

Tally view: tap any pad on the left half → left team +1 · right half → right team +1
Big numbers view: left team's score on the top 4 rows, right team's on the bottom 4 rows (tap the top or bottom half to score)
▲ / ▼ → left team +1 / −1  ·  ► / ◄ → right team +1 / −1
Each team has its own score sound, and reaching the target plays a victory tune.
Session → switch pad view (tally dots ↔ big numbers)
User → undo last change
Stop Solo Mute → hold 1 second to reset the game
Logo lights in the leading team's color (white when tied). Hitting the target score flashes the winner's color.

If it won't connect

Use Chrome or Edge and click Allow when it asks for MIDI access. Close Ableton, Novation Components or any other music app first, because Windows lets only one program use the Launchpad at a time. Unplug and replug it, then press Connect again.
